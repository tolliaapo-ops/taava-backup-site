Privacy Policy

Taava Backup is a personal backup solution used exclusively by its owner.

The application uses Google Drive API with the drive.file scope to create, read, update and delete backup files created by the application.

Google authorization credentials are stored locally on the owner's computer.

Backup data is encrypted locally using Restic before being uploaded to Google Drive.

Google user data is not sold or shared with third parties.

The owner can revoke access through Google Account settings.
